# Developer Portfolio

> Responsive personal portfolio with dark/light theme and a project grid.

## Features

- Responsive layout with CSS grid
- Dark / light theme saved in `localStorage`
- Project cards rendered from data
- Contact form with client-side feedback

## Tech stack

HTML5, CSS3, JavaScript

## Getting started

Open `index.html` in your browser (no build step needed).
